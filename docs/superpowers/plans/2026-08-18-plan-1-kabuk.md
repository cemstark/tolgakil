# Plan 1 — Site Kabuğu Uygulama Planı

> **Ajan çalışanlar için:** ZORUNLU ALT BECERİ: Bu planı görev görev uygulamak için
> `superpowers:subagent-driven-development` (önerilen) veya `superpowers:executing-plans`
> kullanın. Adımlar takip için onay kutusu (`- [ ]`) sözdizimi kullanır.

**Hedef:** Tolga Akıl Hukuk Bürosu sitesinin gezilebilir, erişilebilir ve tasarım
sistemine oturmuş kabuğunu üretmek — henüz veritabanı ve panel yok, içerik sabit.

**Mimari:** Next.js App Router, `src/` düzeni, sunucu bileşenleri. Stil Tailwind'siz:
`globals.css` içinde CSS değişkeni token'ları + bileşen başına `*.module.css`. Bileşenler
renk değeri yazmaz, yalnızca token okur. Yazı tipleri `next/font` ile kendi sunucumuzdan.

**Teknoloji:** Next.js 16.3, React 19, TypeScript 5, Vitest 4, Playwright,
`@axe-core/playwright`.

**Kaynak spec:** `docs/superpowers/specs/2026-08-18-tolga-akil-hukuk-sitesi-design.md`

## Global Kısıtlar

Her görevin gereksinimleri bu bölümü örtük olarak içerir.

- **Sürümler:** Next.js `16.3.x`, React `19.x`, Node `22.x` (`engines.node: "22.x"`).
- **Git yalnızca yerel** (uzak depo yok, `main` dalı). Her görev, doğrulama komutları yeşil
  olduktan **sonra tek bir commit** ile biter. Commit mesajı Türkçe, `tür: özet` biçiminde
  (`feat:`, `test:`, `chore:`), gövdesinde hangi doğrulamanın çalıştırıldığı yazılır.
  `.gitignore` `node_modules/`, `.next/`, `.env*`, `.superpowers/` ve test çıktılarını dışlar.
- **Yol takma adı:** `@/*` → `./src/*`.
- **Kod dili (webstudio deseni, `eslint.config.mjs`/`src/components/*` ile doğrulandı):**
  dosya adları, bileşen adları, tip adları, değişkenler ve CSS sınıf adları **İngilizce**
  (bileşen dosyası PascalCase, CSS sınıfı camelCase). Türkçe kalanlar: rota adları,
  kullanıcıya görünen metinler, test açıklamaları ve kod yorumları.
- **Bileşen deseni:** named export (`export function SiteHeader()`); yalnızca `page.tsx`
  dosyaları `export default`. Prop tipi aynı dosyada, bileşenin üstünde `type XProps = {...}`.
  Ayrı tip dosyası açılmaz. `index.ts` yeniden dışa aktarımı **kullanılmaz**.
- **CSS deseni:** `globals.css` = token'lar + reset + siteye yayılan ortak sınıflar;
  bileşene özgü stiller bileşenle aynı dizinde `Bileşen.module.css`. Koşullu sınıf
  birleştirme template literal ile yapılır, `clsx` eklenmez. Ölçekleme `clamp()` ile.
  **Medya sorguları mobile-first** (`min-width`) — webstudio'daki karışık kullanım
  taşınmaz, tek yaklaşım seçilir.
- **Yorum kültürü:** yorum "ne yaptığını" değil "neden öyle yapıldığını" anlatır, seyrektir.
- **Kod bloklarındaki adlandırma önceliği:** Görev metinlerindeki kod blokları taslaktır ve
  bir kısmı Türkçe tanımlayıcı içerir. **Yukarıdaki "Kod dili" kuralı bu blokları ezer.**
  Uygularken tanımlayıcıları İngilizceye çevir; dosya/bileşen/tip/değişken/CSS sınıfı,
  `id` ve `data-*` öznitelikleri İngilizce olur. Bilinen karşılıklar (bunlara uy, kendin
  yeni isim uydurma):
  `src/content/ornek-icerik.ts` → `src/content/sample-content.ts`;
  `ORNEK_ALANLAR` → `SAMPLE_PRACTICE_AREAS`; `ORNEK_MAKALELER` → `SAMPLE_ARTICLES`;
  `ORNEK_AVUKATLAR` → `SAMPLE_LAWYERS`; `type Alan` → `type PracticeArea`
  (`ad`→`name`, `ozet`→`summary`); `type MakaleOzeti` → `type ArticleSummary`
  (`baslik`→`title`, `kategori`→`category`, `tarih`→`date`); `type AvukatOzeti` →
  `type LawyerSummary` (`ad`→`name`, `unvan`→`title`); prop adları `alanlar`→`areas`,
  `makaleler`→`articles`, `avukatlar`→`lawyers`, `baslik`→`title`;
  `#icerik` → `#content`; `.atlama` → `.skipLink`; `#makaleler` → `#articles`;
  `ana-menu` → `main-menu`; `data-acik` → `data-open`; `acik`/`setAcik` → `open`/`setOpen`;
  CSS sınıfları `hap`→`pill`, `marka`→`brand`, `menuDugmesi`→`menuButton`, `kap`→`inner`,
  `adres`→`address`, `baglantilar`→`links`, `blok`→`block`;
  sayfa fonksiyonları `AnaSayfa`→`HomePage`, `Hakkimizda`→`AboutPage` ve benzeri.
  **Testlerdeki görünür metin ve `getByRole` adları Türkçe kalır** (kullanıcıya görünen
  metin çevrilmez); yalnızca tanımlayıcılar İngilizceye çevrilir. Testlerdeki
  `#icerik`/`#makaleler` seçicileri de yeni İngilizce `id` değerleriyle güncellenir.
- **Route adları Türkçe ve ASCII:** `hakkimizda`, `kadro`, `calisma-alanlari`, `makaleler`,
  `iletisim`, `kvkk`, `cerez-politikasi`, `panel`.
- **Token'lar (`globals.css` `:root`) — spec §7'den birebir:**
  `--ink: #161d27`, `--ink-2: #1f2732`, `--paper: #efece3`, `--paper-2: #f7f5ef`,
  `--gold: #c9a86a`, `--gold-ink: #7d5f26`, `--text-ink: #f3f1ea`,
  `--text-ink-muted: #aab1bc`, `--text-paper: #161d27`, `--text-paper-muted: #4b535f`,
  `--line-ink: rgba(243,241,234,.12)`, `--line-paper: #d5d1c4`.
- **Yarıçap:** hap `999px`, büyük blok `26px`, kart `20px`.
- **Tipografi:** Cormorant Garamond 300/400 başlık, Outfit 300–600 gövde/arayüz.
  Gövde 17px/1.8, h1 56px/1.05 masaüstü ve 36px mobil, h2 40px, eyebrow 11px/3px aralık.
- **`.module.css` dışında renk sabiti yazılmaz; `.module.css` içinde de yalnızca
  `var(--token)` kullanılır.** Yeni bir renk gerekiyorsa önce token eklenir.
- **Erişilebilirlik:** `<html lang="tr">`, semantik başlık hiyerarşisi, 2px odak halkası
  `--focus-ring` üzerinden (koyu zeminde `--gold`, `[data-surface="paper"]` altında
  `--gold-ink`), atlama bağlantısı, `prefers-reduced-motion` desteği, her görselde `alt`.
- **İçerik yasağı (spec §2.1):** "uzman/en iyi", başarı oranı, dava sayısı, müvekkil
  referansı, yorum/yıldız, ücret bilgisi, "ücretsiz görüşme" ifadeleri **hiçbir örnek
  metinde bile** kullanılmaz. Yer tutucu metinler de bu kurala uyar.

- [ ] **Adım 6: Asgari uygulamayı yaz**

`src/lib/slug.ts`:

```ts
// JS'in toLowerCase'i 'İ' harfini birleşik noktalı 'i̇' yapar; bu yüzden Türkçe harfleri
// küçük harfe çevirmeden ÖNCE elle eşliyoruz.
const TR_MAP: Record<string, string> = {
  ç: 'c', Ç: 'c', ğ: 'g', Ğ: 'g', ı: 'i', I: 'i', İ: 'i',
  ö: 'o', Ö: 'o', ş: 's', Ş: 's', ü: 'u', Ü: 'u',
}

export function slugify(input: string): string {
  return input
    .replace(/[çÇğĞıIİöÖşŞüÜ]/g, (ch) => TR_MAP[ch])
    .toLowerCase()
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
}
```
